## 4. B5 实际前向与状态变化

### 4.1 500 地 block4 的逐阶段形状

以本次实际加载的 B5 为例：

1. `ProcessImage`：RGB→灰度→自适应 gamma→28×28→PatchNorm(7)→uint8→[0,1] 幅度；输出 `x:[784]`，batch 后为 `[1,784]`（`dataset.py:345-454`）。
2. reshape：`[1,784]→[1,1,28,28]`。
3. valid conv，C=32、k=5、padding=0：`z:[1,32,24,24]`。
4. ON/OFF：非 free-sign 时，兴奋通道保留 `z`，抑制通道取 `-z`（`conv_snn_layer.py:273-283`）。B5 的 32 个带符号核共享这一通路，`havconnExc` 有 16 个 ON 通道。
5. 阈值：`a=clamp(z_signed-θ_conv,0,0.9)`，`θ_conv:[1,32,1,1]`；得到 `pre_wta:[1,32,24,24]`。
6. local WTA block=4：**每通道、每个不重叠 4×4 空间块各自一个 argmax**，不是跨通道竞争；右/下不能整除处会裁掉。本例无裁边，post-WTA 仍为 `[1,32,24,24]`，每通道 36 个 winner 位置。
7. 池化：对 post-WTA 做 4×4 max-pool，得到 `[1,32,6,6]`，flatten 为 `d:[1,1152]`。
8. feature：`h=W_f d`，`W_f:[2304,1152]`，所以 `h:[1,2304]`。
9. output：`o=W_o h`，`W_o:[500,2304]`，所以 `o:[1,500]`。

block2 正式主表口径则把池化图变为 12×12，conv 描述子为 4608 维，单模块 feature 为 9216 维；不能把 1152 维 B5 旧结果与 4608 维主表当成完全相同容量。

### 4.2 冻结到底冻结什么

**核实**：

- Gabor W 冻结；`calc_stdp_conv` 在 frozen 时直接返回，连符号钳制和 L1 归一化也不执行（`conv_learning.py:91-95`）。
- 但 B5 的 conv 阈值**不是冻结的**：训练分发仍进入 `train_conv_layer`，每样本执行 `θ += η_ip(observed-fire_rate)`，observed 是 pre-WTA 正响应比例，阈值下界默认 0（`conv_learning.py:386-401,460-475`）。
- 下游 feature/output 仍按历史流程训练。因此 B5 不是“整个网络全冻结”，而是“Gabor 核冻结 + conv ITP + 原下游学习”。
- 推理对象 `inference=True` 不创建 `feature.x`、`eta_ip` 等学习状态；本次前向前后所有 state_dict 张量逐元素不变。

checkpoint 中 `conv_layer.thr` 范围 0–0.0479996，18/32 为 0；这与历史 conv ITP 一致。相反，`feature_layer.thr` 的 2304 个值全部为 0，详见下一节。

## 5. feature.x、阈值、抑制稳态、投影和绑定

### 5.1 原 feature 学习实际顺序

训练每个样本时（`VPRTempoTrain.py:446-491`）：

- 若已有前层，先 `no_grad` 前向；conv 用 `conv_forward`，稠密前层用 `linear→clamp_spikes`。
- 当前层先保存 `pre_spike=spikes.detach()`，再算未减阈值的 `noclp=W x`，随后 `spikes=clamp(noclp-θ,0,0.9)`。
- feature 走无监督 STDP；output 走 spike forcing。
- feature 的 `feat_stdp=off` 同时关闭 STDP、符号钳制和 homeostasis；`feat_itp=off` 单独关闭阈值更新（`blitnet.py:544-600,612-654`）。
- 学习率每 100 步按 `(1-t/T)^2` 退火；即使冻结权重/阈值，外层训练循环仍可能运行并退火学习率。

### 5.2 关键源码问题：无监督 ITP 读的是未更新的 x

**核实**：

- `SNNLayer` 训练态把 `self.x` 初始化为全零（`blitnet.py:128-133`）。
- 无监督 feature 分支没有写入 `layer.x`；只有 output spike-forcing 分支在 `blitnet.py:476` 重置并构造强制目标。
- ITP 却执行 `layer.thr += eta_ip*(layer.x-fire_rate)`（`blitnet.py:615-624`）。因此当前 feature 路径的实际更新是向 `θ -= eta_ip*fire_rate`，再以 0 截断，而不是注释所说的当前响应指示。
- 本次直接读取 B5 checkpoint 也看到 `feature_layer.thr` 全零；这是一致性证据，不单独证明所有历史版本都具有相同原因。

本任务**未修复它**。P1 若采用 BP triplet/anchor-only，应绕开该 ITP；若保留历史 F0/F3 对照，必须原样标注其语义，不能暗修后沿用旧结果。

### 5.3 抑制稳态与 output 绑定

- feature 普通 STDP 分别更新正/负连接，再做符号钳制；homeostasis 使用未 clamp 的 `noclp` 调整负权重，放大系数硬编码 50（`blitnet.py:537-600,626-654`）。
- output 的唯一任务标签进入 `idx=round((label-module_offset)/filter)`；在目标输出神经元置 0.5，以 `x_force-x_actual` 更新 output W（`VPRTempoTrain.py:425-433`；`blitnet.py:453-523`）。feature 和 conv 训练不消费地点标签。
- `xdiff.clamp(min=0,max=0.9)` 没有赋值或 in-place（`blitnet.py:477-478`），所以该 clamp 调用不改变 `xdiff`；本次只记录，不修。
- output 的 `fire_rate` 默认零，故其 ITP 条件不满足；checkpoint 的 output 阈值也全零。

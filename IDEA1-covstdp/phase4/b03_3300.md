# B03: 3300-map development search

Status: algorithm implementation locally checked; deployment and GPU submission belong to the operations conversation. Existing published snapshots must stay immutable. Reuse the approved Pixi CUDA environment; there are no dependency changes.

## Protocol

- Reference/training: map IDs 0..3299, spring and fall, 6600 images total; fixed 28x28/patch7/filter8 preprocessing.
- Development queries: summer IDs 600..1099 only. IDs 1100..1149 are a buffer and 1150..3299 are retained for a later locked evaluation. Historical summer exposure must be disclosed. The training/search runner rejects retained-query roles; it does not open retained summer image files.
- Gabor remains the archived block4/1152-D state, including its historical thresholds. Gray is 784-D. Both feature outputs are 2304-D, with fixed zero threshold and no ITP/homeostasis. This global descriptor is not the original 1100-place modular output system.
- Fixed margin 0.1, batch16, SGD without momentum/weight decay, minimum negative gap50 sampled places. Same input/seed shares W0 and the whole negative sequence across methods/lrs. Each run trains at most20 epochs and evaluates/saves at 0/1/4/10/20; preflight overrides to2 epochs, evaluating 0/1/2.

## Output and analysis

Each run records explicit query IDs/role, source/deployment/environment identity, effective config/data hashes, W0/masks, triplet schedule, direct-input and random-feature baselines, predictions, registered checkpoints, activity and loss diagnostics, per-epoch training time, evaluation time and relative weight change. Partial epochs cannot become selected epochs. NaN/Inf and wholly invalid training epochs fail instead of reporting success.

After retrieval use `summarize_task_batch.py --request <fixed-request.json> --run-root <retrieved-or-server-run-root> --output <summary.json>`. The script checks source/protocol/pairing identities, requires complete seed0/1/2 groups and all registered evaluation epochs, and selects one shared lr/epoch by mean development R@1. Incomplete batches write an incomplete report and exit2 without choosing winners. An epoch0 winner means training did not beat the random feature baseline. Retained queries cannot be used for this selection.

Additional tests: `test_task_protocol.py`, existing `test_task_feature.py`, and unchanged `test_run_provenance.py`. These cover sparse/offset GT, retained-query guard, concurrent atomic caches, exact sampler equivalence, 3300-map anchor coverage, common epoch selection, method update checks and deployment/path provenance.

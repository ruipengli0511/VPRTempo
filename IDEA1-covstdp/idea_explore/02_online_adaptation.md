# 方向 2：无标签在线适应旗舰实验（Online Adaptation）

> 2026-09-13｜来源：PLAN §5b 旗舰实验的落地设计
> 一句话卖点：**BP 方法适应新环境需要标签重训；本系统的局部可塑性只需无标签图像流**——部署到 winter 后在线适配，检索增益可量化、不遗忘。
> 雏形证据已存在：B5 无 ITP 时 25/32 通道死亡、+ITP 后 0.660→0.906（S2.9 实测）；B5+BCM 在最难指标 R@100%P 反超 B5 +6.2pt（主表坐实）。本方向把"阈值可塑性"升级为完整的部署适应故事。

## 0. 预注册故事线与判据

- **主张**：冻结先验 + 在线局部可塑性 = 唯一可在部署时无标签自适应的 VPR 系统；适应增益在最难指标上最大（与 B5+BCM 的发现同向）。
- **判据（提前承诺）**：
  - 适应赢：winter 查询 轨B R@1 post − pre ≥ **+3pt**（单 seed 迭代档），且 **遗忘合格**（适应后 summer 轨B R@1 退化 ≤1pt）；
  - 学习价值判定：A3（全 STDP 微调）vs A1/A2（仅阈值）——回答"部署时的无监督学习是否值得"（离线 B6a 是负增益，在线未必：部署数据与目标条件同分布）；
  - 旗舰叙事成立（stretch）：适应后的 winter 系统级数字超过" frozen 前端 + 任何离线变体"。
- **失败出口**：若适应无增益 → 转为诚实分析：哪些统计量漂移、为什么 ITP/BCM 不动点未能跟踪（θ_M/发放率/DC-AC 曲线诊断全落盘），仍是"局部可塑性边界刻画"的一块拼图，与主线不冲突。

## 1. 实验设计

### 1.1 场景与数据

- 参照库：spring+fall（与主表一致，**训练分布不变**）；查询：winter（跨季节极端变化）。
- 适应数据：**无标签 winter 图像**。两种模式（都跑，先 batch 后 online）：
  - **Batch 适应**：winter traverse 前段帧（与查询集不重叠部分，预注册声明帧范围）；
  - **Online 适应**：查询流逐帧经过即适应（部署本义；工程上=按序遍历查询图）。
- 规模：500 地迭代档（单 seed 先行）→ 3300 地确认档 → 正式 3 seeds。

### 1.2 实验臂

| Arm | 前端 | 适应机制 | 回答的问题 |
|---|---|---|---|
| A0 | B5 冻结 | 无 | 零适应对照（= ③ winter 表的 B5 行） |
| A1 | B5 | 仅 ITP 阈值适应（权重 frozen） | 一阶矩适应值多少 |
| A2 | B5 | 仅 BCM 滑动阈值适应（权重 frozen） | 二阶矩适应是否更优（B5+BCM 预期胜者） |
| A3 | B6a 式 | 全 STDP 微调（权重+阈值） | 部署时学习有没有增量（离线负增益的在线检验） |

下游 feature/output 层**全部冻结**（部署时不可能重训监督层——这是叙事的一部分，预注册写明）。

### 1.3 流程（每 arm）

```
1. 加载 spring+fall 训练的模型（与主表同 .pth 同 seed）
2. pre：winter 查询双轨评测（轨A + 轨B）
3. 适应：winter 无标签流过一次（conv 训练循环的 frozen/ITP/BCM 模式，现有机制
   itp_on_frozen / bcm_on_frozen 已实现，A1/A2 近零代码）
4. post：winter 查询双轨评测
5. 遗忘检验：summer 查询双轨评测（与主表 summer 数字对拍）
6. 诊断落盘：θ_M 曲线 / 每通道发放率 / thr 分布 pre→post / DC-AC（PLAN §8-6）
```

### 1.4 工程需求（新脚本 `experiments/adapt_online.py`）

- 加载已有 .pth → 跑适应循环 → 保存 adapted 模型 → 走现有 run_inference / eval_retrieval 评测。
- 注意 run_exp.py 现行行为是训练前删旧模型（规避 input() 交互），**适应脚本不得复用该路径**；模型命名 `<exp_id>__seed<n>_adapted.pth`。
- 配置：phase2 风格 JSON + 新字段 `adapt_data`（适应帧来源声明，预注册帧范围写进配置）。

## 2. 与 ③ 的协同（共享设计，避免重复烧算力）

- A0/A1/A2 的 **pre 行 = ③ winter 主表的 B5/B5+ITP/B5+BCM 行**——同模型同 seed，一次训练两边引用（PLAN 阶梯 R2 的"同一配置跑一次两处引用"惯例）；
- ③ 的叙事表格中，② 贡献 **"+adaptation" 增强行**（winter 表下方一行，预注册标注为探索批）。

## 3. 成本估算（工作站 GPU）

| 档 | 内容 | 成本 |
|---|---|---|
| 迭代档 | 4 arms × 500 地 × seed0（适应 ~2min + 评测 ~3min/arm） | <1h |
| 确认档 | A0/A1/A2 × 3300 地 × seed0 | ~1.5h |
| 正式档 | 4 arms × 3300 地 × 3 seeds + 遗忘检验 | ~6-8h |

一次性工程（adapt_online.py + configs + winter CSV）≈ 1 天。

## 4. 风险与预案

- **winter 28×28 低纹理**：大面积积雪 → 零容差 GT 下天花板可能整体低——这正是适应故事的最佳舞台，但必须诚实报告绝对数字，不藏拙。
- **适应污染查询集**（batch 模式帧选择与查询重叠）→ 预注册声明帧范围（如 skip 前 2400 帧 vs 查询 skip=4800 起），配置内写明。
- **A3 灾难性遗忘** → 遗忘检验是合格线而非可选项；若 A3 遗忘超标而增益高，如实报"学习有增益但需保护机制"，引出未来的 EWC 式局部正则讨论（不进本文）。
- 红旗：适应增益若只出现在轨B而轨A不动，回到方向 1 的读出修复后重测（两方向在此交汇）。

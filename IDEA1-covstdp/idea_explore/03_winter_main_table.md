# 方向 3：winter 跨季节主表（Winter Main Table）

> 2026-09-13｜动机：现有主表查询全是 summer（spring,fall→summer 同为绿色植被季），审稿人可攻击"季节变化太温和"。
> winter（积雪/低纹理/光照剧变）是 Nordland 的标准硬骨头，也是 VPR 文献的必争场景。
> 定位：**不是替换 summer 主表，而是新增一张"极端条件表"**（正文或附录视篇幅），同时充当 ② 在线适应的对照舞台。

## 0. 预注册判据与解读（提前承诺，防事后挑数）

设 B5−B0 差距为 D_summer（3300 地轨A R@1，已知 +12.0pt），winter 表跑完后：

| 观察 | 解读 | 叙事动作 |
|---|---|---|
| D_winter ≥ D_summer | 前端价值在极端条件下**放大** | 最强结果：主文表格 + "鲁棒性放大"小节 |
| D_winter ≈ D_summer | 前端价值与条件无关 | 稳健性声明（"不依赖温和季节"） |
| D_winter < D_summer 但 B5 仍 > B0 | 极端条件下增益收窄 | 转向 ② 适应故事：收窄量 = 可适应空间的量化 |
| DCT−B5 差 winter ≈ summer（−2~3pt） | 频率覆盖原理跨季节成立 | "好前端原理"的泛化性证据（机制节的支撑） |

## 1. 实验设计

### 1.1 阵容（预注册，防无限加格）

6 个变体 × 2 规模 × 3 seeds × 双轨 = 72 格：

- B0（基线）/ B2（从零学习）/ B2+BCM（学习+BCM）——学习路线全覆盖
- B5（手工 Gabor）/ B5+BCM（winner 组合）——主线
- DCT 基（频率无方向）——机制对照（频率覆盖原理的跨季节检验）

### 1.2 协议

- 查询 = winter；skip=4800 / query=2700（3300 地，与 summer 主表逐参数同口径）；500 地 skip=0。
- GT：单位矩阵零容差（与主表一致）。
- 参照库、训练配置、种子、评测脚本与主表完全一致——**唯一变量是 query_dir: summer→winter**（这正是预注册的干净性所在：一张表只变一个变量）。
- exp_id 命名：`w1_<variant>_<scale>`（与 `t1_` 同构，隔离清晰）。

### 1.3 工程需求

- **winter CSV 生成**（唯一前置）：`vprtempo/src/create_data_csv.py` 按 nordland 既有格式生成 `nordland-winter.csv`（与 spring/fall/summer CSV 逐列同构；用现有四季文件名模式校验）。
- configs：`phase3/configs/` 风格，`w1_` 系列（500 单文件 + 3300 train/eval 三件；查询目录改 winter，适应臂的帧范围声明见 ②）。
- 复用 `run_table1.sh` / `make_table1.py` 管线（加 winter 变体映射）。

### 1.4 与 ② 的协同（避免重复烧算力）

- `w1_b5_*` 的模型与 A0 同一 .pth（spring+fall 训练，与查询季节无关——模型训练从不用查询数据）；
- winter 表完成后，② 的 A1/A2/A3 直接加载这些模型做适应——**winter 表的 B5 行 = A0 的 pre 行，一次训练两处引用**；
- ② 的 post 行以 "+adaptation" 探索行附在 winter 表下（预注册标注）。

## 3. 风险与预案

- **winter 整体天花板低**（积雪低纹理 + 零容差）：预注册解读表的第三行已覆盖；绝对数字低不丢人——winter 上所有人（含 LoCS-Net 系）都掉，且我们的核心主张是"差距"而非绝对值。
- **snow cover 导致的大面积近似常数 patch**：输入直方图证据需补采（winter 版 `input_histogram_patchnorm.png`，50 张）——支撑 DC/阈值适应的机制讨论，**事后无法补采，必须随首跑落盘**（PLAN S1.2 的教训）。
- 查询帧质量校验：人工抽查 winter 查询图像可读性（skip=4800 之后积雪段比例），写入配置注释。
- 红旗：winter 表数字与 ② 适应数字**必须同批模型同 seed 产出**，严禁跨批次拼接（PLAN §8-5 孤儿结果禁令）。

## 4. 论文位置（预案）

- 最优情况（D_winter ≥ D_summer）：正文 Table（winter 主表）+ 一句话摘要 hook 升级为"极端季节下仍 +N 点"；
- 常规情况：附录表 + 正文一段（与 summer 表并置的鲁棒性声明）；
- ② 适应成功时：winter 表 + 适应行合并成"部署适应性"核心节——这是机器人会议最买账的故事形态。
